## Gotchas (cost hours this session — don't repeat)

- **Operator manifests are `//go:embed`-baked** into the binary. Editing `operator/manifests/*.tmpl`
  does nothing until you rebuild+push the operator image and roll it. **Bump `OPERATOR_TAG`** each time
  so the roll pulls a new tag (rolling the same `:vN` is a cache no-op).
- **`post.logout.redirect.uris`**: set the real origin(s) `origin##origin/*`. `+` and `origin/*`-only
  are silently accepted (204) but NOT honored. Set reliably via `kcadm update clients/<id> -f <file.json>`
  (a partial `{"attributes":{...}}`), not `kcadm -s` (dotted key breaks) or curl sed-hacking.
- **Front-channel logout is required** — backchannel `--backend-logout-url` alone leaves the browser
  Keycloak SSO cookie → silent re-login.
- **Post-logout target = `<origin>/oauth2/start`**, not the bare origin (bare origin 403s → white screen
  since luigi-config.js is protected; `/oauth2/start` re-initiates login).
- **`luigi-config.js` must be `Cache-Control: no-cache`** or the browser serves a stale config
  (heuristic freshness) and old logout/nav wiring persists — looks like "server not fixed" when it is.
- **Frontend `VITE_*` build args** are baked at build; a missing one → `requireEnv` throws
  `Missing required environment variable` → whole MFE dies → "no access". Docker layer cache can reuse
  an arg-less `npm run build`; use `--no-cache` if a rebuilt frontend still lacks the value.
